# 波士顿房价预测：梯度下降法

这是一个线性回归练习。程序读取仓库中的波士顿房价 CSV，根据平均房间数、到就业中心的距离等特征，预测各地区自住房屋价值的中位数（千美元）。

## 运行方法

克隆仓库后，在项目目录中安装依赖并运行脚本：

```bash
python -m pip install numpy pandas scikit-learn
python "波士顿房价预测梯度下降法.py"
```

脚本会自动读取同目录下的 `boston_house_prices.csv`。

## 实现流程

1. 按 80% 和 20% 划分训练集和测试集。
2. 用训练集拟合 `StandardScaler`，再对两组数据应用相同的标准化。
3. 用 `SGDRegressor` 训练线性回归模型，输出模型系数、截距和测试集预测结果。
4. 计算 MAE（平均绝对误差）、MSE（均方误差）和 RMSE（均方根误差）。
